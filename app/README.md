# 多算法预测界面

`index.html`、`app.css`、`app.js` 是无需构建工具的本地网页，由公共 API 服务一起提供。

已实现：

- 选择预测算法及已保存的模型版本。
- 输入一条或多条评论。
- 调用公共 `api/` 后端。
- 展示每条评论的情感类别。

算法是否可选由后端实际支持情况决定。目前 TF-IDF + LogisticRegression 和 TF-IDF + RandomForest 可用，
fastText、BERT 已接入，训练保存权重后自动可选；LLM 仍待接入。
版本框区分原始、量化、蒸馏模型，尚无权重时不会启用该算法。
运行 `python scripts/09_serve_app.py` 后打开 `http://127.0.0.1:8765`。
选择算法和模型版本，一行输入一条评论，点击“开始预测”；也可点击“填入示例”快速体验。
支持 Ctrl+Enter 预测、清空内容、刷新本地模型列表；空输入、超长输入和服务错误均有提示。
未接入或尚无模型的算法不可选择，页面显示的预测全部来自后端实际模型。
