# MiHoYo Sense

面向米哈游游戏社区的内容理解、玩家评论分析与个性化内容推荐学习项目。

项目计划整合米游社、B站与抖音中关于《原神》《崩坏：星穹铁道》《绝区零》的文章、视频文本与评论，分析玩家讨论的主题、态度和兴趣，并探索跨平台差异与内容推荐。

> 当前阶段：需求规划与项目初始化。下文为开发待办，不代表功能已经实现。
> 最后更新：2026-10-18。
> 当前先逐步学习和本地实现；本次仅维护 README，不上传业务代码或原始数据。

## 项目目标

- 理解文章和视频在讨论什么：剧情、角色、攻略、联动、活动、二创等。
- 分析评论的讨论对象、情感态度与兴趣信号。
- 比较相同游戏、相同事件在不同平台上的讨论差异。
- 根据一条评论或平台内的历史评论，推荐相关内容并给出推荐理由。
- 完成从数据获取、EDA、清洗、标注、建模到推荐评估的学习实践，形成可复现的实验记录。

第一版以文本为主。视频标题、简介、字幕或转写文本应分别记录；音频和画面理解作为后续扩展，不列为首版必须完成项。

## 首阶段目录规划

以下是本地待创建结构，不表示这些目录已经存在于仓库中。

```text
hoyo-sense/
├── README.md
├── data/
│   ├── raw/
│   │   ├── miyoushe/
│   │   │   ├── genshin/
│   │   │   ├── starrail/
│   │   │   └── zzz/
│   │   ├── bilibili/
│   │   │   ├── genshin/
│   │   │   ├── starrail/

│   │       ├── genshin/
│   │       ├── starrail/
│   │       └── zzz/
│   └── processed/
├── scripts/
└── notebooks/
```

| 路径 | 用途 |
| --- | --- |
| data/raw/ | 保存原始数据，后续清洗不覆盖它 |
| data/processed/ | 保存清洗后数据，有实际数据后再建立平台与游戏子目录 |
| scripts/ | 存放可运行的采集、清洗等脚本 |
| notebooks/ | 逐步查看数据、进行 EDA 和绘图 |

剧情、角色、联动等主题以字段记录，不按主题拆文件夹。后续有实际需要时，再增加 configs、src、tests、outputs 等目录。
