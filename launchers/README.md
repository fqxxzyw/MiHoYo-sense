# 双击启动采集

在 Windows 资源管理器中双击对应 `.bat` 文件，无需记终端命令。

| 文件 | 任务 |
| --- | --- |
| 采集全部游戏.bat | 依次采集原神官方资讯、星穹铁道首页、绝区零首页 |
| 采集原神.bat | 原神官方资讯批次；每 20 页先采正文和评论 |
| 采集星铁.bat | 仅运行星穹铁道批次 |
| 采集绝区零.bat | 仅运行绝区零批次 |
| 只发现帖子.bat | 只发现三个游戏的首页推荐，累计最多 20 页，不采正文或评论 |

脚本自动切换到项目根目录，使用 `D:\Anaconda3\envs\hoyosense\python.exe`。其他电脑请修改各文件中的 `PYTHON_EXE`。文件以 UTF-8 编码保存，运行时切换至代码页 65001；窗口结束后保留输出，并返回 Python 的退出代码。

批次按“发现至多 20 页 → 采集本批正文、顶层评论、楼中楼 → 下一批发现”执行；有旧列表时先处理旧候选。

数量上限、间隔和超时仍读取 `configs/miyoushe.json`，启动文件不改写配置。本次仓库配置新增 `discovery.max_pages=null`（总上限取消）和 `discovery.batch_pages=20`（每批页数）；旧配置缺少 `discovery` 配置时，累计发现页数默认 10；如需取消发现上限，可添加与 `collection` 平级的 `"discovery": {"max_pages": null, "batch_pages": 20}`。四个评论/帖子采集上限保持原值。

已有 raw 与断点继续复用；推荐列表达到上限不等于全站采集完成。当前已结束的发现快照不会自动刷新。启动文件本身不删除或重置数据。

每次选择一个入口；全部游戏入口已依次处理三个游戏，避免再同时启动其他入口造成重复任务和叠加请求频率。需要中止时按 Ctrl+C，等待程序保存中断状态后退出。

原神单独入口与全部游戏入口均使用资讯采集器；`--batch` 自动选择游戏来源，`--batch-home` 保留旧首页模式。各游戏共用 `_batches/<game>/`，旧混合批次文件保留，单帖 JSON 及断点仍在原目录。
